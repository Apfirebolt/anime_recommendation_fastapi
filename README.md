 A FastAPI service for browsing anime and manga catalogs, searching by natural-language vibe, and retrieving precomputed similar titles. The production API is available at:

 **https://recommendation.softgenie.org**

 Interactive OpenAPI documentation:

 **https://recommendation.softgenie.org/docs**

 Raw OpenAPI schema:

 **https://recommendation.softgenie.org/openapi.json**

 ## Features

 - Paginated anime and manga catalog endpoints.
 - Case-insensitive search across title and domain-specific metadata.
 - Genre, publication/air date, and configurable sorting filters.
 - Detail endpoints keyed by MyAnimeList (`mal_id`).
 - Ten precomputed similar titles included with each detail response.
 - Natural-language semantic search powered by `sentence-transformers` and `all-MiniLM-L6-v2`.
 - PostgreSQL persistence through SQLAlchemy and Alembic migrations.
 - CORS support for the deployed and local web clients.

 ## Quick Start

 ### Requirements

 - Python 3.10 or newer.
 - PostgreSQL.
 - A working C compiler may be required by some scientific Python dependencies on a fresh machine.

 ### Install

 ```bash
 git clone <repository-url>
 cd anime_recommendation_system

 python3 -m venv .venv
 source .venv/bin/activate       # macOS/Linux
 # .venv\\Scripts\\activate      # Windows PowerShell

 pip install -r requirements.txt
 ```

 The first application start downloads the `all-MiniLM-L6-v2` model from Hugging Face unless it is already present in the local model cache.

 ### Configure the database

 Create a `.env` file in the project root:

 ```dotenv
 DATABASE_USER=postgres
 DATABASE_PASSWORD=your-password
 DATABASE_HOST=localhost
 DATABASE_PORT=5432
 DATABASE_NAME=anime_recommendation
 ```

 The application builds a PostgreSQL connection URL from these five variables. Do not commit `.env` or database credentials.

 ### Create the schema

 ```bash
 alembic upgrade head
 ```

 ### Start the API

 ```bash
 uvicorn main:app --host 0.0.0.0 --port 8000 --reload
 ```

 Local URLs:

 - API root: http://localhost:8000/
 - Swagger UI: http://localhost:8000/docs
 - ReDoc: http://localhost:8000/redoc
 - OpenAPI JSON: http://localhost:8000/openapi.json

 ## Data and Cache Preparation

 The repository expects filtered CSV datasets at `data/anime_filtered.csv` and `data/manga_filtered.csv`. These files are not generated by the API itself.

 Seed the PostgreSQL tables and compute database-backed top-ten similarity relationships:

 ```bash
 python -m scripts.seed_anime
 python -m scripts.seed_manga
 ```

 The seed scripts clear and repopulate their respective tables, so use them carefully in shared environments.

 Build the embedding caches used by vibe search:

 ```bash
 python -m scripts.generate_cache
 python -m scripts.generate_manga_cache
 ```

 These commands create `anime_cache.pkl` and `manga_cache.pkl` in the project root. They contain serialized records and vectors and should be treated as generated artifacts, not source data.

 On startup, the API loads the shared SentenceTransformer model and both cache files into memory. If a cache is missing, catalog and detail endpoints can still use PostgreSQL, but the corresponding vibe-search endpoint returns an empty result list until the cache is generated.

 ## API Reference

 All endpoints are unauthenticated and return JSON. The hosted Swagger UI at [`/docs`](https://recommendation.softgenie.org/docs) is the authoritative reference for the deployed version.

 ### Health and metadata

 | Method | Path | Description |
 | --- | --- | --- |
 | `GET` | `/` | Returns a welcome message. |
 | `GET` | `/api/health` | Returns the service health message. |

 ```bash
 curl https://recommendation.softgenie.org/api/health
 ```

 ```json
 {"message":"FastAPI Anime Recommendation API is healthy"}
 ```

 ### Anime

 #### `GET /api/anime/`

 Returns a paginated anime list.

 Query parameters:

 | Parameter | Type | Description |
 | --- | --- | --- |
 | `page` | integer | Page number, starting at `1`. |
 | `size` | integer | Items per page. The deployed OpenAPI currently advertises a default of `50` and maximum of `100`; local source defaults may differ. |
 | `search` | string | Matches title, English title, genre, or studio. |
 | `genre` | string | Matches a genre such as `Action`. |
 | `aired_after` | `YYYY-MM-DD` | Include anime aired on or after this date. |
 | `aired_before` | `YYYY-MM-DD` | Include anime aired on or before this date. |
 | `sort_by` | string | `popularity`, `highest_voted`, `most_episodes`, `newest`, `oldest`, `favorites`, or `rank`. |

 Example:

 ```bash
 curl 'https://recommendation.softgenie.org/api/anime/?search=cyberpunk&genre=Action&sort_by=highest_voted&page=1&size=10'
 ```

 Response shape:

 ```json
 {
	 "items": [
		 {
			 "mal_id": 6675,
			"title": "Weathering with You",
			 "title_english": "Weathering with You",
			 "type": "Movie",
			 "source": "Original",
			 "episodes": 1,
			 "score": 8.2,
			 "rank": 100,
			 "popularity": 50,
			 "genres": "Romance|Supernatural",
			 "synopsis": "...",
			 "image_url": "https://..."
		 }
	 ],
	 "total": 1,
	 "page": 1,
	 "size": 10,
	 "pages": 1
 }
 ```

 `title`, `mal_id`, and the pagination metadata are required. Other catalog fields may be `null`.

 #### `GET /api/anime/{mal_id}`

 Returns full anime details plus a `similar_anime` array ordered by recommendation rank. Similarity entries contain `rank`, `similarity_score`, `mal_id`, `title`, `genres`, `synopsis`, `image_url`, and `score`.

 ```bash
 curl https://recommendation.softgenie.org/api/anime/1
 ```

 Additional detail fields include `title_japanese`, `status`, `aired_from`, `aired_to`, `rating`, `studios`, and `themes`.

 #### `GET /api/anime/vibe-search`

 Finds anime by semantic similarity to a natural-language description. The query is compared with precomputed synopsis embeddings.

 | Parameter | Type | Description |
 | --- | --- | --- |
 | `q` | string, required | Description such as `gritty cyberpunk action with hackers`. |
 | `limit` | integer | Number of results. Deployed API accepts `1`-`20`; default is `10`. |

 ```bash
 curl 'https://recommendation.softgenie.org/api/anime/vibe-search?q=gritty%20cyberpunk%20action%20with%20hackers&limit=5'
 ```

 The response is an object with a `results` array. Each result includes the cached anime record plus `vibe_match_score`, a rounded score expressed as a percentage from the cosine similarity calculation.

 ### Manga

 Manga follows the same structure as anime:

 | Method | Path | Description |
 | --- | --- | --- |
 | `GET` | `/api/manga/` | Paginated list with search, genre, publication-date, and sorting filters. |
 | `GET` | `/api/manga/{mal_id}` | Full manga details plus `similar_manga`. |
 | `GET` | `/api/manga/vibe-search` | Natural-language semantic manga search. |

 `GET /api/manga/` supports `page`, `size`, `search`, `genre`, `published_after`, `published_before`, and `sort_by`. Manga search matches title, English title, genre, author, or serialization. Supported sort values are `popularity`, `highest_voted`, `most_chapters`, `most_volumes`, `newest`, `oldest`, `favorites`, and `rank`.

 ```bash
 curl 'https://recommendation.softgenie.org/api/manga/?search=samurai&sort_by=highest_voted'
 curl https://recommendation.softgenie.org/api/manga/2
 curl 'https://recommendation.softgenie.org/api/manga/vibe-search?q=philosophical%20samurai%20journey&limit=5'
 ```

 Manga catalog fields include `mal_id`, `title`, `title_english`, `type`, `chapters`, `volumes`, `score`, `rank`, `popularity`, `genres`, `synopsis`, and `image_url`. Detail responses additionally include `title_japanese`, `status`, `publishing`, `published_from`, `published_to`, `authors`, `serializations`, `themes`, `demographics`, and `similar_manga`.

 ## Errors and Validation

 - `200 OK`: Request completed successfully.
 - `404 Not Found`: The requested anime or manga `mal_id` does not exist.
 - `422 Unprocessable Entity`: A path or query parameter failed validation, for example a non-integer `mal_id`, an invalid date, or a `limit` outside its allowed range.
 - `500 Internal Server Error`: An unexpected database or application error occurred.

 FastAPI validation errors have this general shape:

 ```json
 {
	 "detail": [
		 {
			 "loc": ["query", "limit"],
			 "msg": "Input should be greater than or equal to 1",
			 "type": "greater_than_equal"
		 }
	 ]
 }
 ```

 ## Development and Testing

 Run the endpoint test suite:

 ```bash
 pytest
 ```

 The tests mock the database and recommendation services, so they do not require populated PostgreSQL tables or generated embedding caches. For an integration check, configure `.env`, run the migrations and seed/cache commands, then start the API and call `/api/health`, a catalog route, and a vibe-search route.

 ## Architecture

 1. FastAPI receives the request and validates query/path parameters.
 2. Catalog and detail requests query PostgreSQL through SQLAlchemy.
 3. Detail requests join the relevant similarity table and return ranked precomputed recommendations.
 4. Vibe search encodes only the incoming query with `all-MiniLM-L6-v2`, then compares it with vectors loaded from the corresponding pickle cache using cosine similarity.
 5. The production process is served behind Nginx and exposed at `recommendation.softgenie.org`.

 ## Deployment Notes

 A production process can be started with:

 ```bash
 uvicorn main:app --host 0.0.0.0 --port 8002
 ```

 The included `conf.nginx` proxies HTTPS traffic for `recommendation.softgenie.org` to `127.0.0.1:8002`. Keep the model and both cache files available in the application working directory, run migrations before starting the service, and ensure the process has access to the configured PostgreSQL instance.
